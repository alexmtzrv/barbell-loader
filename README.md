## About the Project

As an athlete with years of experience in CrossFit, I would often struggle to calculate percentages for my lifts, whether I was rushing to load different weights during an EMOM or simply trying to make the most of limited training time.

That's how the idea for **Barbell Loader** was born.

Barbell Loader offers athletes a quick visual guide showing which plates to load on each side of the barbell. I built this app with athletes in mind who just want to get their hands on the bar and lift, without distractions or spending more time struggling with the calculations than with the WOD itself.

---

## ✨ Features

- 🎯 Calculates a target weight based on an athlete's PR and desired percentage.
- 🏋️ Supports both **35 lb** and **45 lb** barbells.
- 🧮 Automatically calculates which plates should be loaded on each side.
- 🎨 Displays plates visually using their corresponding weight colors.
- 🔢 Shows the quantity of each plate required.
- ⚖️ Displays remaining weight when the target cannot be loaded exactly with the available plates.
- ✅ Validates user input and prevents invalid calculations.
- 🧹 Allows athletes to clear all previous calculations.
- 📱 Responsive interface designed for both mobile and desktop use.

---

## ⚙️ How It Works

Using Barbell Loader only takes a few steps:

1. Select your **barbell weight**.
2. Enter your **PR weight**.
3. Enter the **percentage** you want to train at.
4. Press **LOAD WEIGHT**.
5. Barbell Loader calculates your target weight and shows exactly which plates to load on each side of the barbell.

## 🧠 What I Learned

Building Barbell Loader gave me the opportunity to turn a real-world problem into a complete web application.

During development, I practiced and improved my understanding of:

- DOM manipulation and dynamic element creation.
- Working with arrays and objects to represent application data.
- Breaking application logic into reusable functions.
- Building an algorithm to calculate plate combinations.
- Dynamically rendering calculation results.
- Form validation and handling edge cases.
- Responsive web design.
- Designing a user interface in Figma and translating it into HTML and CSS.
- Testing and debugging across desktop and mobile devices.
- Using Git and GitHub throughout the development process.
- Deploying and testing a production application with Vercel.

One of the biggest lessons from this project was learning that building an application is not only about making the main calculation work. Handling unexpected inputs, designing a clear interface, testing on real devices, and refining the user experience were equally important parts of the process.
